# Site de Notícias do JEC

Projeto de página web dedicada a notícias e informações sobre o Joinville Esporte Clube (JEC), desenvolvido com HTML5 e CSS3.

## Sobre o Projeto

Este portal tem como objetivo apresentar as principais novidades, notícias recentes e a escalação do elenco de jogadores do Joinville Esporte Clube.

## Funcionalidades

- Cabeçalho de Navegação: Barra superior com logotipo oficial do JEC apontando para o site do clube e links de navegação.
- Seção de Notícias: Cards visuais informativos destacando as últimas novidades da equipe.
- Seção de Escalação: Galeria de cards apresentando fotos e nomes dos jogadores do elenco.
- Mascote Oficial: Elemento gráfico fixado no canto da tela com o mascote do clube.
- Estilização Temática: Design responsivo e alinhado às cores oficiais do clube (vermelho, preto e branco).

## Tecnologias Utilizadas

- HTML5
- CSS3
